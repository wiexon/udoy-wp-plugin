# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with GitHub's **Report a vulnerability** button on the
[Security tab](https://github.com/wiexon/udoy-wp-plugin/security/advisories/new) of this repository.
Include the plugin version, what you found and steps to reproduce it. We will acknowledge your report and keep you
informed until it is fixed.

## Supported versions

Only the latest released version of Udoy Connect receives security fixes.
